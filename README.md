# 32点FFT快速实现

基于原始FFT16函数的高效32点快速傅里叶变换实现。

## 文件说明

- **`fft32.c`** - 最优的32点FFT实现（推荐使用）
- **`fft32_validation.c`** - 完整的验证测试程序
- **`fft32_validation_report.md`** - 详细的验证报告

## 核心函数

```c
void fft32(float *vec);
```

**参数**：
- `vec`: 包含32个复数的数组（64个float），采用交错存储格式：
  - `vec[0], vec[1]` = 第0个复数的实部和虚部
  - `vec[2], vec[3]` = 第1个复数的实部和虚部
  - ...
  - `vec[62], vec[63]` = 第31个复数的实部和虚部

## 性能特点

- ✅ **高效算法**: 基于分治策略，复杂度O(N log N)
- ✅ **数值稳定**: 使用预计算常数，精度误差 < 10⁻⁵
- ✅ **内存优化**: 复用已验证的FFT16函数
- ✅ **工业级**: 适合生产环境使用

## 技术细节

该实现采用经典的Cooley-Tukey算法：
1. 将32点输入分解为两个16点子问题
2. 分别对偶数和奇数索引样本执行FFT16
3. 通过旋转因子和蝶形运算合并结果

算法已通过多种测试信号验证，确保正确性和数值稳定性。
